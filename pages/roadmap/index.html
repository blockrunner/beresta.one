2020
Старт проекта · Береста 1.0 Завершено

Первый прототип на Arduino. Матрица 8×8 из 64 электродов. Исследование принципов электростимуляции кожи для передачи информации.

  • ✓Концепция устройства
  • ✓Первый прототип на Arduino
  • ✓Тестирование электростимуляции
  • ✓Вывод: переход на вибромоторы
✓
2021–2022
Береста 2.0 → 3.0 → 3.2 Завершено

Переход с электродов на вибромоторы. Три итерации конструкции. Разработка веб-интерфейса управления. Подтверждение нейропластичности в ходе тестов.

  • ✓128 вибромоторов на силиконовой подложке
  • ✓Web Bluetooth API управление
  • ✓Веб-интерфейс с очередью сигналов
  • ✓Положительная динамика распознавания паттернов
  • ✓3D-модель устройства
