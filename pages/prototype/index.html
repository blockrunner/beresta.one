Береста 3.2

128 вибромоторов на силиконовой подложке, управляемых через 8 промежуточных плат с помощью программируемого микроконтроллера. Сигналы дублируются на компактный дисплей. Управление через веб-интерфейс по протоколу Web Bluetooth API.

Габариты браслета 295 × 120 × 35 мм
Уровень шума (макс.) 71 дБ-A (без контакта с поверхностью)
Управление Web Bluetooth API, веб-интерфейс
Дисплей Дублирует тактильные сигналы визуально
Форм-фактор Лабораторный (тестирование)

История версий

Каждое поколение — это новые уроки и шаг к реальному устройству

1.0
Береста 1.0 Завершено

Arduino + промежуточная плата + матрица из 64 электродов. Передача сигналов с помощью постоянного электрического тока. Тестирование выявило критическую проблему: длительное воздействие тока повреждало кожу и усиливало болевые ощущения, что делало долгосрочное обучение невозможным.

Решение: переход с электродов на вибромоторы.

Arduino 64 электрода Постоянный ток Матрица 8×8
2.0
Береста 2.0 Завершено

Замена электродов на вибромоторы. Новая прошивка микроконтроллера. Более длительные тесты показали положительную динамику в распознавании сигнала — мозг начинал адаптироваться к паттернам. Конструкция оказалась ненадежной и неудобной в управлении.

Решение: полный редизайн конструкции → Береста 3.0 → 3.2

Вибромоторы Обновленная прошивка Подтверждена нейропластичность
3.2
Береста 3.2 Текущая версия

128 вибромоторов, 8 промежуточных плат, программируемый МК. Дисплей дублирует тактильные сигналы. Полноценный веб-интерфейс с управлением очередью сигналов, настройкой длительности, задержек и выбором руки. Подключение через Web Bluetooth API. Активно используется для тестирования паттернов и сбора обучающих данных.

128 вибромоторов 8 плат управления Web Bluetooth API Веб-интерфейс Дисплей
4.0
Береста 4.0 — MVP В разработке

Модульная система, электротактильные актуаторы, платформа с API. Управляющий блок у запястья (до 40 × 10 мм), основная часть — тонкая многослойная структура с LRA-моторами 5×5×5 мм в сетке 7–10 мм. Влагозащита, звукоизоляция, четыре ремешка с равномерным натяжением. Мобильное приложение без установки.

Цель: 300 г Цель: <35 дБ-A LRA-моторы 5×5×5 мм Модульная архитектура Open API Блокчейн-интеграция
